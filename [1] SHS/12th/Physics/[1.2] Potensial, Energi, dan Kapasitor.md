## Potensial/Tegangan Listrik
Usaha utk memindahkan 1 muatan antar titik
### Persamaan
| $V=\frac{w}{q'}$                                                                              | $V=k\frac{Q}{r}$                                                                                                   | $V=\int E\space dr$                                                                                 | $V_{2}-V_{1}=kQ\left( \frac{1}{r_{2}}-\frac{1}{r_{1}} \right)$ |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| $V=$ potensial/tegangan listrik $(V)$<br>$w=$ usaha berpindah $(J)$<br>$q'=$ muatan uji $(C)$ | $k=$ konstanta coulomb $(9*10^9\space Nm^2/C^2)$<br>$Q=$ muatan sumber $(C)$<br>$r=$ jarak trhdp suatu titik $(m)$ | $E=$ [[[1.1] Muatan dan Medan Listrik#Medan Listrik\|medan listrik]] $(N/C)$<br>$d=$ *differential* | $r_{1,2}=$ posisi awal, akhir muatan $(m)$                     |

| $V=V_{1}+V_{2}$                                                                                     | $V=\sum k\frac{Q_{i}}{r_{i}}$                                                                                   |
| --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| $V=$ resultan potensial/tegangan listrik $(V)$<br>$V_{1,2}=$ potensial listrik $Q_{1}, Q_{2}$ $(V)$ | $k=$ konstanta coulomb $(9*10^9\space Nm^2/C^2)$<br>$Q_{i}=$ muatan i $(C)$<br>$r_{i}=$ jarak ke muatan i $(m)$ |

## Energi Potensial Listrik
Energi perpindahan dlm medan listrik
### Persamaan
![[Pasted image 20260722215556.png|253]]

| $Ep=\frac{kQq'}{r}$                                                                                                                                                                       | $W=Ep_{A}-Ep_{B}=kQq'\left( \frac{1}{r_{B}}-\frac{1}{r_{A}} \right)$                       |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| $Ep=$ energi potensial listrik $(J)$<br>$k=$ konstanta coulomb $(9*10^9\space Nm^2/C^2)$<br>$Q=$ muatan sumber $(C)$<br>$q'=$ muatan uji/berpindah $(C)$<br>$r=$ jarak antar muatan $(m)$ | $W=$ [[#Usaha Listrik\|usaha listrik]] $(J)$<br>$r_{A,B}=$ posisi awal, akhir muatan $(m)$ |
### Resultan
![[Pasted image 20260722221807.png|252]]

| $Ep_{1}=Ep_{12}+Ep_{13}$                                                                                                                                                                                      | $Ep=\sum kQ\frac{Q_{i}}{r_{i}}$                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| $Ep_{1}=$ resultan energi potensial listrik $Q_{1}\space (J)$<br>$Ep_{12}=$ energi potensial listrik $Q_{1}$ akibat $Q_{2}\space (J)$<br>$Ep_{13}=$ energi potensial listrik $Q_{1}$ akibat $Q_{3}\space (J)$ | $k=$ konstanta coulomb $(9*10^9\space Nm^2/C^2)$<br>$Q_{i}=$ muatan i $(C)$<br>$r_{i}=$ jarak antar muatan $(m)$ |
## Usaha Listrik
Energi utk memindahkan muatan
### Persamaan
| $W=kQq\left( \frac{1}{r_{A}}-\frac{1}{r_{B}} \right)$                                                                                                                                         | $W=-q\triangle V$                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| $W=$ usaha listrik $(J)$<br>$k=$ konstanta coulomb $(9*10^9\space Nm^2/C^2)$<br>$Q=$ muatan sumber $(C)$<br>$q=$ muatan uji $(C)$<br>$r_{A,B}=$ jarak muatan A/akhir, B/awal dgn sumber $(m)$ | $V=$ [[#Potensial/Tegangan Listrik\|potensial/tegangan listrik]] $(V)$ |
#### Dengan Energi Potensial Listrik
| $W=\triangle Ep$                                                                                                  | $W=kQq\left( \frac{1}{r_{A}}-\frac{1}{r_{B}} \right)$                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| $W=$ usaha listrik $(J)$<br>$\triangle Ep=$ selisih [[#Energi Potensial Listrik\|energi potensial listrik]] $(J)$ | $k=$ konstanta coulomb $(9*10^9\space Nm^2/C^2)$<br>$Q=$ muatan sumber $(C)$<br>$q=$ muatan uji $(C)$<br>$r_{A,B}=$ jarak muatan A, B dgn sumber $(m)$ |
#### Dengan Potensial Listrik
| $W=-q\triangle V$                                                                                                                 | $W=q(V_{2}-V_{1})$                                                                       |
| --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| $W=$ usaha listrik $(J)$<br>$q=$ muatan berpindah $(C)$<br>$V=$ [[#Potensial/Tegangan Listrik\|potensial/tegangan listrik]] $(V)$ | $V_{1,2}=$ [[#Potensial/Tegangan Listrik\|potensial/tegangan listrik]] awal, akhir $(V)$ 
#### Dengan Energi Mekanik
| $Em=Ep+Ek=$ konstan                                                                              | $Em_{1}=Em_{2}$ | $qV_{1}+\frac{1}{2}mv_{1}^2=qV_{2}+\frac{1}{2}mv_{2}^2$                                                                                                                                             | $q(V_{1}-V_{2})=\frac{1}{2}m(v_{2}^2-v_{1}^2)$ |
| ------------------------------------------------------------------------------------------------ | --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| $Em=$ energi mekanik $(J)$<br>$Ep=$ energi potensial listrik $(J)$<br>$Ek=$ energi kinetik $(J)$ |                 | $q=$ muatan $(C)$<br>$V_{1,2}=$ [[#Potensial/Tegangan Listrik\|potensial/tegangan listrik]] awal, akhir $(V)$<br>$m=$ massa muatan $(kg)$<br>$v_{1,2}=$ kecepatan muatan posisi awal, akhir $(m/s)$ |                                                |

| $C = \frac{Q}{V}$                                                                                                                    | <center>Konversi</center>                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| $C=$ kapasitansi listrik (Farad)<br>$Q=$ muatan $(C)$<br>$V=$ beda [[#Potensial/Tegangan Listrik\|potensial/tegangan listrik]] $(V)$ | 1 mikro Farad $(\mu F) = 10^{-6}\space F$<br>1 nano Farad $(nF) = 10^{-9}\space F$<br>1 piko Farad $(pF) = 10^{-12}\space F$ |
### Kasus
| <center>Udara/ruang hampa</center>                                                                                                                                                                 | <center>Bahan dielektrikum</center>                                                    |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| $C_{0} = \frac{\varepsilon_{0}A}{d}$                                                                                                                                                               | $C_{D} = \frac{\varepsilon_{r}\varepsilon_{0}A}{d}$                                    |
| $C_{0}=$ kapasitansi ruang hampa (Farad)<br>$\varepsilon_{0}=$ permitivitas ruang hampa $(8.85*10^{-12}\space N^{-1}m^{-2}C^2)$<br>$A=$ luas permukaan plat $(m^2)$<br>$d=$ jarak antar plat $(m)$ | $C_{D}=$ kapasitansi dielektrikum (Farad)<br>$\varepsilon_{r}=$ konstanta dielektrikum |
### Energi Tersimpan
| $Ep = \frac{1}{2}CV^2$                                                                                                                                                                   | $Ep = \frac{1}{2}\frac{Q^2}{C}$ | $Ep = \frac{1}{2}VQ$ |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- | -------------------- |
| $Ep=$ [[#Energi Potensial Listrik\|energi potensial listrik]]$(J)$<br>$C=$ kapasitansi (Farad)<br>$V=$ beda [[#Potensial/Tegangan Listrik\|potensial/tegangan listrik]] antar plat $(V)$ | $Q=$ muatan plat $(C)$          |                      |
### Medan Listrik
| $E = \frac{V}{d}$                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| $E=$ medan listrik pd ruang kapasitor $(N/C)$<br>$V=$ [[#Potensial/Tegangan Listrik\|potensial/tegangan listrik]] $(V)$<br>$d=$ jarak antar plat $(m)$ |
### Rangkaian
#### Seri
| <center>Muatan $(q)$</center> | <center>Potensial $(V)$</center> | <center>Kapasitas $(C)$</center>                                        |
| ----------------------------- | -------------------------------- | ----------------------------------------------------------------------- |
| $Q=Q_{1}=Q_{2}=Q_{n}$         | $V=V_{1}+V_{2}+\dots+V_{n}$      | $\frac{1}{C_{s}}=\frac{1}{C_{1}}+\frac{1}{C_{2}}+\dots+\frac{1}{C_{n}}$ |
#### Paralel
| <center>Muatan $(q)$</center> | <center>Potensial $(V)$</center> | <center>Kapasitas $(C)$</center> |
| ----------------------------- | -------------------------------- | -------------------------------- |
| $Q=Q_{1}+Q_{2}+\dots Q_{n}$   | $V=V_{1}=V_{2}=V_{n}$            | $C_{P}=C_{1}+C_{2}+\dots+C_{n}$  |
