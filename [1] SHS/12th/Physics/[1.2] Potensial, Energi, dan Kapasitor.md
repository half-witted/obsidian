## Potensial Listrik
Usaha utk memindahkan 1 muatan antar titik
### Persamaan
| $V=\frac{w}{q'}$                                                                               | $V=k\frac{Q}{r}$                                                                                                           | $V=\int E\space dr$                                                                           | $V_{2}-V_{1}=kQ\left( \frac{1}{r_{2}}-\frac{1}{r_{1}} \right)$ |
| ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| $V=$ potensial listrik $(V)$<br>$w=$ usaha berpindah $(J)$<br>$q'=$ muatan uji/berpindah $(C)$ | $k=$ konstanta coulomb $(9*10^9\space \frac{Nm^2}{C^2})$<br>$Q=$ muatan sumber $(C)$<br>$r=$ jarak trhdp suatu titik $(m)$ | $E=$ [[[1] SHS/12th/Physics/[1.1] Muatan dan Medan Listrik\|medan listrik]] $(\frac{N}{C})$<br>$d=$ *differential* | $r_{1,2}=$ posisi awal, akhir muatan $(m)$                     |

## Energi Listrik
Energi perpindahan dlm medan listrik
### Persamaan
![[Pasted image 20260722215556.png|253]]

| $Ep=\frac{kQq'}{r}$                                                                                                                                                                               | $W=Ep_{A}-Ep_{B}=kQq'\left( \frac{1}{r_{B}}-\frac{1}{r_{A}} \right)$                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| $Ep=$ energi potensial listrik $(J)$<br>$k=$ konstanta coulomb $(9*10^9\space \frac{Nm^2}{C^2})$<br>$Q=$ muatan sumber $(C)$<br>$q'=$ muatan uji/berpindah $(C)$<br>$r=$ jarak antar muatan $(m)$ | $W=$ [[#Usaha Listrik\|usaha listrik]] $(J)$<br>$r_{A,B}=$ posisi awal, akhir muatan $(m)$ |
### Resultan
![[Pasted image 20260722221807.png|252]]

| $Ep_{1}=Ep_{12}+Ep_{13}$                                                                                                                                                                                      | $Ep_{1}=k\frac{Q_{1}Q_{2}}{r_{12}}+k\frac{Q_{1}Q_{3}}{r_{13}}$                                                                         | $Ep=\sum kQ\frac{Q_{i}}{r_{i}}$ |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| $Ep_{1}=$ resultan energi potensial listrik $Q_{1}\space (J)$<br>$Ep_{12}=$ energi potensial listrik $Q_{1}$ akibat $Q_{2}\space (J)$<br>$Ep_{13}=$ energi potensial listrik $Q_{1}$ akibat $Q_{3}\space (J)$ | $k=$ konstanta coulomb $(9*10^9\space \frac{Nm^2}{C^2})$<br>$Q_{1,2,3}=$ muatan 1, 2, 3 $(C)$<br>$r_{1,2,3}=$ jarak antar muatan $(m)$ |                                 |
### Usaha Listrik
Energi utk memindahkan muatan
#### Persamaan
##### Dengan Energi Potensial Listrik
| $W=\triangle Ep$                                                                   | $W=kQq\left( \frac{1}{r_{2}}-\frac{1}{r_{1}} \right)$                                                                                                             |
| ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| $W=$ usaha listrik $(J)$<br>$\triangle Ep=$ selisih energi potensial listrik $(J)$ | $k=$ konstanta coulomb $(9*10^9\space \frac{Nm^2}{C^2})$<br>$Q=$ muatan sumber $(C)$<br>$q=$ muatan berpindah $(C)$<br>$r_{1,2}=$ posisi awal, akhir muatan $(m)$ |
##### Dengan Potensial Listrik
| $W=q\triangle V$                                                                        | $W=q(V_{2}-V_{1})$                             |
| --------------------------------------------------------------------------------------- | ---------------------------------------------- |
| $W=$ usaha listrik $(J)$<br>$q=$ muatan berpindah $(C)$<br>$V=$ potensial listrik $(V)$ | $V_{1,2}=$ potensial listrik awal, akhir $(V)$ 
##### Dengan Energi Mekanik
| $Em=Ep+Ek=$ konstan                                                                              | $Em_{1}=Em_{2}$ | $qV_{1}+\frac{1}{2}mv_{1}^2=qV_{2}+\frac{1}{2}mv_{2}^2$                                                                                                                                                | $q(V_{1}-V_{2})=\frac{1}{2}m(v_{2}^2-v_{1}^2)$ |
| ------------------------------------------------------------------------------------------------ | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------- |
| $Em=$ energi mekanik $(J)$<br>$Ep=$ energi potensial listrik $(J)$<br>$Ek=$ energi kinetik $(J)$ |                 | $q=$ muatan $(C)$<br>$V_{1,2}=$ [[#Potensial Listrik\|potensial listrik]] awal, akhir $(V)$<br>$m=$ massa muatan $(kg)$<br>$v_{1,2}=$ kecepatan muatan posisi awal, akhir $\left( \frac{m}{s} \right)$ |                                                |
