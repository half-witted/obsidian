## Konsep
### Pengertian
- Muatan listrik yg tk mengalir (bergerak dgn kesinambungan)
- Terjadi saat partikel bermuatan berinteraksi tanpa sumber tegangan
- Ex: petir, penggaris dgn rambut dan kertas

![[Pasted image 20260721202851.png|214]]
#### Jenis
- Netral: proton $=$ elektron
- Negatif: kelebihan elektron
- Positif: kekurangan elektron

- Sejenis akan saling tolak-menolak

## Gaya Coulomb/Gaya Listrik
Gaya tarik-menarik, tolak-menolak
### Persamaan
| $F=k\frac{q_{A}q_{B}}{r^2}$                                                                                                                                                        | $k=\frac{1}{4\pi \varepsilon_{0}\varepsilon_{r}}$                                                                                                  | $F_{r}=\frac{F_{u}}{\varepsilon_{r}}$                                          |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| $F=$ gaya coulomb  $(N)\to$ ruang hampa<br>$k=$ konstanta coulomb $(9*10^9\space Nm^2/C^2)$<br>$q_{A}=$ muatan A $(C)$<br>$q_{B}=$ muatan B $(C)$<br>$r=$ jarak antar muatan $(m)$ | $\varepsilon_{0}=$ permitivitas ruang hampa $(8.85*10^{-12}\space N^{-1}m^{-2}C^2)$<br>$\varepsilon_{r}=$ permitivitas relatif $(N^{-1}m^{-2}C^2)$ | $F_{r}=$ gaya coulomb relatif $(N)$<br>$F_{u}=$ gaya coulomb ruang hampa $(N)$ |
### Resultan
#### Satu Garis Lurus
![[Pasted image 20260721203505.png|244]]

| $F_{2}=\pm F_{21}\pm F_{23}$                                                                                                                               |                                                                                    |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| $F_{2}=$ resultan gaya coulomb $Q_{2}$ $(N)$<br>$F_{21}=$ gaya coulomb $Q_{2}$ akibat $Q_{1}$ $(N)$<br>$F_{23}=$ gaya coulomb $Q_{2}$ akibat $Q_{3}$ $(N)$ | $+$ jika vektor searah $x^+$ atau $y^+$<br>$-$ jika vektor searah $x^-$ atau $y^-$ |

| $F_{2}=$ resultan gaya coulomb $Q_{2}$ $(N)$<br>$F_{2x}=$ gaya coulomb $Q_{2}$ akibat $Q_{x}$ $(N)$<br>$F_{2y}=$ gaya coulomb $Q_{2}$ akibat $Q_{y}$ $(N)$<br>$\theta=$ sudut pd $F_{2x}$ dgn $F_{2y}$ |                                         |
## Medan Listrik
Daerah sekitar muatan yg menimbulkan gaya listrik pd muatan lain
### Garis Gaya Listrik
Garis khayal yg menunjukkan arah medan listrik
![[Pasted image 20260721204657.png|242]]
#### Sifat-Sifat
- Muatan positif ke luar, negatif ke dalam
- Garis tk berpotongan satu sm lain
- Semakin dekat garis trhdp muatan, semakin rapat
- Semakin banyak garis, medan listrik semakin kuat
### Persamaan
| $E=\frac{F}{q'}$                                                                                               | $E=k\frac{Q}{r^2}$                                                                                            |
| -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| $E=$ medan listrik $(N/C)$<br>$F=$ [[#Gaya Coulomb/Gaya Listrik\|gaya coulomb]] $(N)$<br>$q'=$ muatan uji$(C)$ | $k=$ konstanta coulomb $(9*10^9\space Nm^2/C^2)$<br>$Q=$ muatan sumber $(C)$<br>$r=$ jarak antar muatan $(m)$ |
### Resultan
#### Satu Garis Lurus
![[Pasted image 20260721205713.png|233]]

| $E=\pm E_{1}\pm E_{2}$                                                                                                                          |                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| $E=$ resultan medan listrik $(\frac{N}{C})$<br>$E_{1}=$ medan listrik $Q_{1}$ $(\frac{N}{C})$<br>$E_{2}=$ medan listrik $Q_{2}$ $(\frac{N}{C})$ | $+$ jika vektor searah $x^+$ atau $y^+$<br>$-$ jika vektor searah $x^-$ atau $y^-$ |
#### Sudut Tertentu
![[Pasted image 20260721210141.png|212]]

| <center>Jajar genjang</center>                                                                                                                                                                | <center>Analisis vektor $x, y$</center> |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| $E=\sqrt{ E_{1}^2+E_{2}^2+2E_{1}E_{2}\cos \theta }$                                                                                                                                           | $E=\sqrt{ E_{x}^2+E_{y}^2 }$            |
| $E=$ resultan medan listrik $(\frac{N}{C})$<br>$E_{1}=$ medan listrik $Q_{1}$ $(\frac{N}{C})$<br>$E_{2}=$ medan listrik $Q_{2}$ $(\frac{N}{C})$<br>$\theta=$ sudut antara $E_{1}$ dgn $E_{2}$ |                                         |
### Hukum Gauss
| <center>Tegak Lurus</center>                                                                         | <center>Sudut terhadap Garis Lurus</center>                                                                                                                                                                |
| ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| $\phi=EA$                                                                                            | $\phi=E \cos \theta A=\frac{1}{\varepsilon_{0}}q$                                                                                                                                                          |
| $\phi=$ fluks listrik ($Wb$ atau weber)<br>$E=$ medan listrik $(N/C)$<br>$A=$ luas permukaan $(m^2)$ | $\theta=$ sudut dgn vektor ($\cos=$ vektor dgn bidang, $\sin=$ vektor dgn garis normal)<br>$\varepsilon_{0}=$ permitivitas ruang hampa $(8.85*10^{-12}\space N^{-1}m^{-2}C^2)$<br>$q=$ jumlah muatan $(C)$ |
