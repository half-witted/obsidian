## Besaran
### Amplitudo ($A$)
Nilai maksimum simpangan

| <center>Transversal</center>         | <center>Longitudinal</center>   |
| ------------------------------------ | ------------------------------- |
|                                      |                                 |
| Titik puncak/dasar ke titik seimbang | Titik seimbang ke titik terjauh |
|                                      |                                 |
### Frekuensi dan Periode
| $f=\frac{1}{T}$ | $f=$ frekuensi ($Hz$)<br>$T=$ periode ($s$) |
| --------------- | ------------------------------------------- |
#### Frekuensi ($f$)
Banyak gel. tiap detik

| $f=\frac{n}{t}$ | $n=$ banyak gel.<br>$t=$ waktu ($s$) |
| --------------- | ------------------------------------ |
#### Periode ($T$)
Waktu utk 1 gel. merambat

| $T=\frac{t}{n}$ | $n=$ banyak gel.<br>$t=$ waktu ($s$) |
| --------------- | ------------------------------------ |
### Panjang Gelombang
| $\lambda=\frac{s}{n}$ | $\lambda=$ panjang ($m$)<br>$s=$ jarak yg ditempuh n gel. ($m$)<br>$n=$ banyak gel. merambat |
| --------------------- | -------------------------------------------------------------------------------------------- |
### Fase Gelombang
Kondisi partikel pada gelombang
1. Sefase
	- $\lambda=$ bilangan bulat
	- Arah getar, besar simpangan sama (B dan F $\to \lambda=1$, C dan K $\to \lambda=2$)
2. Beda fase
	- Berlawanan fase
		- $\lambda=$ kelipatan ganjil dari $\frac{1}{2}$
		- Arah getar beda, besar simpangan sama (C dan E $\to \lambda=\frac{1}{2}$, D dan J $\to \lambda=\frac{3}{2}$)
	- Tidak sefase
		- $\lambda=$ selain di atas
		- Besar simpangan beda, berjarak sembarang (C dan F $\to \lambda=\frac{3}{4}$, H dan I $\to \lambda=\frac{1}{4}$)

### Frekuensi Sudut ($\omega$)

| $\omega=\frac{2\pi}{T}=2\pi f$ | $\omega=$ frekuensi sudut ($\frac{rad}{s}$)<br>$T=$ [[#Periode ($T$)\|periode]] ($s$)<br>$f=$ [[#Frekuensi ($f$)\|frekuensi]] ($Hz$) |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
### Bilangan Gel. ($k$)

| $k=\frac{2\pi}{\lambda}$ | $k=$ bilangan gel. ($\frac{rad}{m}$)<br>$\lambda=$ [[#Panjang Gelombang\|panjang]] ($m$) |
