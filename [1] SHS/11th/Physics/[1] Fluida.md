## Fluida Statis
### Massa Jenis
| $\rho=\frac{m}{v}$                                                                 | $\rho_{1}h_{1}=\rho_{2}h_{2}$ |
| ---------------------------------------------------------------------------------- | ----------------------------- |
| $\rho=$ massa jenis ($\frac{kg}{m^3}$)<br>$m=$ massa ($kg$)<br>$v=$ volume ($m^3$) | $h=$ tinggi ($m$)             |
### Tekanan
| <center>Zat padat</center>                                                              | <center>Hidrostatis</center>                                                                                                                                                             | <center>Total</center>                                                            | <center>Raksa</center> |
| --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ---------------------- |
| $P=\frac{F}{A}$                                                                         | $P_{h}=\rho gh$                                                                                                                                                                          | $P_{t}=P_{0}+P_{h}$                                                               | $P_{luar}=P_{dalam}+h$ |
| $P=$ tekanan ($Pa$ atau $\frac{N}{m^2}$)<br>$F=$ gaya ($N$)<br>$A=$ luas bidang ($m^3$) | $P_{h}=$ tekanan hidrostatis ($Pa$ atau $\frac{N}{m^3}$)<br>$\rho=$ [[#Massa Jenis\|massa jenis]] ($\frac{kg}{m^3}$)<br>$g=$ gravitasi ($10\space\frac{m}{s^2}$)<br>$h=$ kedalaman ($m$) | $P_{0}=$ tekanan atmosfer<br>          ($1.01*10^5\space Pa$ atau $1 \space atm$) | $P_{h}=h$              
### Hukum Pascal
| $P_{1}=P_{2}$                                                | $\frac{F_{1}}{A_{1}}=\frac{F_{2}}{A_{2}}$                                                      |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| $P_{1,2}=$ [[#Tekanan\|tekanan]] ($Pa$ atau $\frac{N}{m^2}$) | $F_{1,2}=$ gaya penampang kecil, besar ($N$)<br>$A_{1,2}=$ luas penampang kecil, besar ($m^2$) |
### Hukum Archimedes
| $F_{A}=\rho gV$                                                                                                                                                       | $F_{A}=W_{u}-W_{f}$<br>$F_{A}=mg-T$<br>$\frac{F_{A}}{W_{u}}=\frac{\rho_{f}}{\rho_{b}}$                                                                                                                                       |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| $F_{A}=$ gaya archimedes ($N$)<br>$\rho=$ [[#Massa Jenis\|massa jenis]] ($\frac{kg}{m^3}$)<br>$g=$ gravitasi ($10\space \frac{m}{s^2}$)<br>$V=$ volume fluida ($m^3$) | $W_{u,f}=$ berat di udara, fluida ($N$)<br>$m=$ massa benda ($kg$)<br>$g=$ gravitasi ($10\space \frac{m}{s^2}$)<br>$T=$ tegangan tali ($N$)<br>$\rho_{f,b}=$ [[#Massa Jenis\| massa jenis]] fluida, benda ($\frac{kg}{m^3}$) 

| <center>Terapung</center>         | <center>Melayang</center>         | <center>Tenggelam</center>        | <center>Menentukan</center>                            |
| --------------------------------- | --------------------------------- | --------------------------------- | ------------------------------------------------------ |
| $F_{A}=W$ dan $\rho_{f}>\rho_{b}$ | $F_{A}=W$ dan $\rho_{f}=\rho_{b}$ | $F_{A}<W$ dan $\rho_{f}<\rho_{b}$ | $\frac{V_{tercelup}}{V_{b}}=\frac{\rho_{b}}{\rho_{f}}$ |
### Kapilaritas
| $h=\frac{2\lambda \cos\theta}{\rho gr}$ | $h=$ naik/ turun permukaan fluida ($m$)<br>$\gamma=$ [[#Tegangan Permukaan\|tegangan permukaan]] ($\frac{N}{m}$)<br>$\theta=$ sudut kontak<br>$\rho=$ [[#Massa Jenis\|massa jenis]] ($\frac{kg}{m^3}$)<br>$g=$ gravitasi ($10\space s^2$)<br>$r=$ jari2 pipa kapiler ($m$) |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
- Kohesi: tarik menarik antar partikel sejenis
- Adhes: beda jenis
- Kohesi > adhesi $\to$ zat turun, sebaliknya
### Tegangan Permukaan
| $\gamma=\frac{F}{d}$                                                                            | $\gamma=\frac{F}{2L}$      |
| ----------------------------------------------------------------------------------------------- | -------------------------- |
| $\gamma=$ tegangan permukaan ($\frac{N}{m}$)<br>$F=$ gaya ($N$)<br>$d=$ panjang permukaan ($m$) | $L=$ panjang kawat L ($m$) |
## Fluida Dinamis
### Debit
| $Q=\frac{V}{t}$              | $Q=Av$                                                               |
| ---------------------------- | -------------------------------------------------------------------- |
| $Q=$ debit ($\frac{m^3}{s}$) | $A=$ luas penampang ($m^2$)<br>$v=$ kecepatan aliran ($\frac{m}{s}$) |
### Asas Kontinuitas
| $A_{1}v_{1}=A_{2}v_{2}$ | $A_{1,2}=$ luas penampang 1, 2 ($m^2$)<br>$v_{1,2}=$ kecepatan aliran 1, 2 ($\frac{m}{s}$) |
| ----------------------- | ------------------------------------------------------------------------------------------ |
### Asas Bernoulli
| $P+\rho gh+\frac{1}{2}\rho v^2=$ konstan                                                                                                                                                                                             | $P_{1}+(\rho gh)_{1}+(\frac{1}{2}\rho v^2)_{1}=P_{2}+(\rho gh)_{2}+(\frac{1}{2}\rho v^2)_{2}$ |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| $P=$ [[#Tekanan\|tekanan]] ($Pa$ atau $\frac{N}{m^2}$)<br>$\rho=$ [[#Massa Jenis\|massa jenis]] ($\frac{kg}{m^3}$)<br>$g=$ gravitasi ($10\space \frac{m}{s^2}$)<br>$h=$ posisi fluida ($m$)<br>$v=$ kecepatan aliran ($\frac{m}{s}$) |                                                                                               |
- Contoh: pesawat, semprotan, venturimeter, etc
