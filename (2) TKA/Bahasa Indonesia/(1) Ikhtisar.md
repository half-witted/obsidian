## Pengertian
Teks <mark style="background:#40a9ff">ringkas</mark> berdasarkan teks aslinya

| <center>Teks</center> | <center>Perbedaan</center>                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------- |
| Ikhtisar              | - Biasa disebut intisari<br>- Boleh ubah urutan gagasan<br>- Bahasa sendiri                             |
| Ringkasan             | Urutan, kerangka asli masih jelas                                                                       |
| Rangkuman             | - Asli dan rangkuman harus proporsional<br>- Menyatukan pokok2 informasi terpisah<br>- POV asli ttp ada |
| Sinopsis              | Disertakan pd teks asli yg ditulis dlm narasi pendek                                                    |
## Struktur
<mark style="background:#40a9ff">Sama</mark> dgn struktur teks <mark style="background:#40a9ff">asli</mark> cuma lbh ringkas
