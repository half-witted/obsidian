## Unsur-Unsur
| <center>Unsur</center>^unsur | <center>Penjelasan/Contoh</center>                       |
| ---------------------------- | -------------------------------------------------------- |
| Kelas interval               | - Kelas 1 $=31-40$<br>- Kelas 2 $=41-50$                 |
| Batas kelas                  | - $Bb=$ batas bawah<br>- $Ba=$ batas atas                |
| Tepi kelas                   | - $Tb=Bb-$ ketelitian data<br>- $Ta=Ba-$ ketelitian data |
| Panjang kelas                | $p=Ta-Tb$                                                |
| Titik tengah kelas           | $X_{i}=\displaystyle\frac{Ba+Bb}{2}$                     |
## Pemusatan Data
### Data Tunggal
| <center>Ukuran</center> | <center>Rumus</center>                      | <center>Keterangan</center>                               |
| ----------------------- | ------------------------------------------- | --------------------------------------------------------- |
| Mean                    | $\bar{x}=\displaystyle\frac{\sum x_{i}}{n}$ | $\bar{x}=$ mean<br>$x_{i}=$ data ke-i<br>$n=$ jumlah data |
| Modus                   |                                             | Urutin, cari nilai yg sering muncul                       |
| Median                  |                                             | Urutin, cari nilai tengah                                 |
### Data Kelompok
| <center>Ukuran</center> | <center>Rumus</center>                                                                              | <center>Keterangan</center>                                                                                                                                                                                                                            |
| ----------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Mean                    | $\bar{x}=\displaystyle\frac{\sum f_{i}x_{i}}{\sum f_{i}}$                                           | $\bar{x}=$ mean<br>$f_{i}=$ frekuensi data ke-i<br>$x_{i}=$ nilai tengah kelas                                                                                                                                                                         |
| Modus                   | $Mo=Tb+p\displaystyle\left( \frac{d_{1}}{d_{1}+d_{2}} \right)$                                      | $Mo=$ modus<br>$Tb=$ [[#^unsur\|tepi bawah]] kelas modus<br>$p=$ [[#^unsur\|panjang]] kelas modus<br>$d_{1}=$ selisih frekuensi kelas modus dgn kelas sebelum<br>$d_{2}=$ dgn kelas sesudah                                                            |
| Median                  | $Me=Tb+\displaystyle\frac{p\left( \frac{n}{2}-\sum f_{kumulatif\space sebelumnya} \right)}{f_{Me}}$ | $Me=$ median<br>$Tb=$ [[#^unsur\|tepi bawah]] kelas median<br>$p=$ [[#^unsur\|panjang]] kelas median<br>$n=$ jumlah seluruh frekuensi<br>$\sum f_{kumulatif\space sebelumnya}=$ frekuensi kumulatif sebelum kelas median<br>$f_{Me}=$ frekuensi median |
