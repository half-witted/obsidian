## Unsur-Unsur
| <center>Unsur</center>^unsur | <center>Penjelasan/Contoh</center>                       |
| ---------------------------- | -------------------------------------------------------- |
| Kelas interval               | - Kelas 1 $=31-40$<br>- Kelas 2 $=41-50$                 |
| Batas kelas                  | - $Bb=$ batas bawah<br>- $Ba=$ batas atas                |
| Tepi kelas                   | - $Tb=Bb-$ ketelitian data<br>- $Ta=Ba-$ ketelitian data |
| Panjang kelas                | $p=Ta-Tb$                                                |
| Titik tengah kelas           | $X_{i}=\displaystyle\frac{Ba+Bb}{2}$                     |
