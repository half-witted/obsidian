## Sifat
| <center>Jenis</center> | <center>Rumus</center>                         |
| ---------------------- | ---------------------------------------------- |
| Ganjil                 | $(-a)^n=-a^n$                                  |
| Genap                  | $(-a)^n=a^n$                                   |
| Penjumlahan            | $a^m*a^n=a^{m+n}$                              |
| Perkalian              | $(a^m)^n=a^{m*n}$                              |
| Dipangkatkan           | $(a*b)^m=a^m*b^m$                              |
| Pengurangan            | $\frac{a^m}{a^n}=a^{m-n}$                      |
| Nol                    | $a^0=1$                                        |
| Negatif                | $a^{-n}=\frac{1}{a^n}$                         |
| Bilangan pecahan       | $\left( \frac{a}{b} \right)^m=\frac{a^m}{b^m}$ |
| Pecahan                | $^n\sqrt{ a^m }=a^{m/n}$                       |
