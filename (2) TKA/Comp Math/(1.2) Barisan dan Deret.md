## Aritmetika
### Barisan Aritmetika
Suku2 berdekatan punya beda ttp/sama.

| <center>Rumus</center> | <center>Perumusan</center> | <center>Keterangan</center>                      |
| ---------------------- | -------------------------- | ------------------------------------------------ |
| Beda                   | $b = U_{n}-U_{n-1}$        | $b=$ beda suku<br>$U_{n}=$ nilai suku ke-n       |
| Suku ke-n              | $U_{n} = a+(n-1)b$         | $a=$ nilai suku pertama/awal<br>$n=$ urutan suku |
### Deret Aritmetika
Penjumlahan n suku pertama dr barisan aritmetika.

| <center>Rumus</center>           | <center>Keterangan</center>                                                                                      |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| $S_{n} = \frac{n}{2}(2a+(n-1)b)$ | $S_{n}=$ jumlah n suku pertama<br>$n=$ banyak suku yg dijumlah<br>$a=$ nilai suku pertama/awal<br>$b=$ beda suku |
| $S_{n} = \frac{n}{2}(a+U_{n})$   | $U_{n}=$ nilai suku ke-n                                                                                         |

## Geometri

### Barisan Geometri
Pola dgn rasio ttp $(r)$ utk tiap 2 suku berdekatan.

| <center>Rumus</center> | <center>Perumusan</center>  | <center>Keterangan</center>                                       |
| ---------------------- | --------------------------- | ----------------------------------------------------------------- |
| Rasio                  | $r = \frac{U_{n}}{U_{n-1}}$ | $r\neq 0$ dan $r\neq 1$<br>$r=$ rasio<br>$U_{n}=$ nilai suku ke-n |
| Suku ke-n              | $U_{n} = ar^{n-1}$          | $a=$ nilai suku pertama/awal                                      |
### Deret Geometri
Penjumlahan n suku pertama barisan geometri.

| <center>Kondisi</center> | <center>Rumus</center>         | <center>Keterangan</center>                                                                                   |
| ------------------------ | ------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| $-1<r<1$                 | $S_{n} = \frac{a(1-r^n)}{1-r}$ $S_{n}=$ jumlah suku n pertama<br>$a=$ nilai suku pertama/awal<br>$r=$ rasio<br>$n=$ banyak suku yg dijumlah k  |
| $r<-1$ atau $r>1$        | $S_{n} = \frac{a(r^n-1)}{r-1}$                                                                                                                 |
