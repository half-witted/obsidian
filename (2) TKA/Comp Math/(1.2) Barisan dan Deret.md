## Barisan Aritmetika
Suku2 berdekatan punya beda ttp/sama.

| <center>Rumus</center> | <center>Perumusan</center> | <center>Penjelasan</center>                      |
| ---------------------- | -------------------------- | ------------------------------------------------ |
| Beda                   | $b = U_{n}-U_{n-1}$        | $b=$ beda suku<br>$U_{n}=$ nilai suku ke-n       |
| Suku ke-n              | $U_{n} = a+(n-1)b$         | $a=$ nilai suku pertama/awal<br>$n=$ urutan suku |
## Deret Aritmetika
Penjumlahan n suku pertama dr barisan aritmetika.

| <center>Rumus</center>            | <center>Penjelasan</center>                                                    |
| --------------------------------- | ------------------------------------------------------------------------------ |
| $S_{n} = U_{1}+U_{2}+\dots+U_{n}$ | $S_{n}=$ jumlah n suku pertama<br>$U_{n}=$ nilai suku ke-n                     |
| $S_{n} = \frac{n}{2}(2a+(n-1)b)$  | $n=$ banyak suku yg dijumlah<br>$a=$ nilai suku pertama/awal<br>$b=$ beda suku |
| $S_{n} = \frac{n}{2}(a+U_{n})$    |                                                                                |
