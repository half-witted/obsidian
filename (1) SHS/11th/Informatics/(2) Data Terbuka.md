## Konsep
### Definisi
Data yg boleh diakses, digunakan, diubah, dibagikan siapa aja scr gratis
### Karakteristik
| <center>Karakteristik</center> | <center>Penjelasan</center>                                |
| ------------------------------ | ---------------------------------------------------------- |
| Aksesibilitas                  | Tersedia *online,* dpt diakses siapa aja tanpa izin khusus |
| *Machine readable*             | Dlm format yg dpt dibaca mesin (JSON, CSV, XML)            |
| Keterbukaan lisensi            | Punya lisensi hukum jelas                                  |
| Transparasi                    | Terbuka utk umum tanpa batasan, dpt verif                  |
| Gratis atau murah              |                                                            |
| Universalitas                  | Dpt dipake umum dan di mana aja, tanpa batasan negara      |
| Keterbaruan                    | Diperbarui rutin agar akurat, cocok                        |
| Interoperabilitas              | Dpt digabungkan data lain                                  |
| Dpt didistribusi ulang         |                                                            |
### Sumber
Data pemerintah, organisasi inter (WHO, NASA), komunitas (Kaggle, OpenStreetMap)
### Manfaat
- Meningkatkan transparasi: dpt memantau kebijakan scr langsung
- Mendorong inovasi
- Kerjasama global
- Kebijakan efektif: membantu membuat kebijakan
## Aspek
### Lisensi
#### *Creative Commons* (CC)
Utk karya kreatif

| <center>Lisensi</center> | <center>Penjelasan</center>                                        |
| ------------------------ | ------------------------------------------------------------------ |
| CC BY                    | Bebas (dipake, diubah, disalin, dibagikan) asal cantumkan pencipta |
| CC BY-SA                 | Bebas tpi karya turunan wajib pake lisensi sama                    |
| CC BY-NC                 | Bebas utk non-komersial                                            |
| CC BY-ND                 | Boleh dipake dan dibagikan, gk boleh diubah                        |
#### *Open Data Commons* (ODC)
Khusus utk data

| <center>Lisensi</center> | <center>Penjelasan</center>                                    |
| ------------------------ | -------------------------------------------------------------- |
| ODC BY                   | Bebas asal cantumkan sumber                                    |
| ODC-ODbL                 | Bebas, hasil modif pake lisensi sama dan menjaga keaslian data |
| PDDL                     | Bebas total                                                    |
#### *Gnu General Public License* (GPL)
Bebas, hasil lisensi sama
#### MIT *License*
Bebas tpi cantumkan hak cipta dlm kode
### Hak dan Kewajiban
| <center>Hak</center>                       | <center>Kewajiban</center>             |
| ------------------------------------------ | -------------------------------------- |
| Mengakses, mengunduh, membaca              | Mencantumkan pencipta sesuai ketentuan |
| Menggunakan data utk keperluan             | Mengikuti lisensi                      |
| Membagikan pd org lain sesuai lisensi      | Melindungi privasi                     |
| Memodifikasi data utk karya turunan (bbrp) | Menggunakan data scr etis              |
### Etika Penggunaan
- Transparasi: menggunakan data scr jujur, tk memanipulasi data
- Privasi: tk menyebarkan informasi pribadi
- Manfaat: digunakan utk membawa manfaat
- Tk melanggar hak org: menghindari plagiarisme dan mematuhi aturan
- Pencegahan penyalahgunaan: memastikan data bkn utk kejahatan
